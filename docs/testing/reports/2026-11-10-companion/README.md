`voice-capsule.js` 和 `voice-capsule.css`。接口、任务及语音由临时测试页

  `probe-run-2`，界面转为 STOPPED。

  107px，实际 scrollHeight 1079px；scrollWidth/clientWidth 均为 352px，
  无水平撑出。区域可聚焦，按 PageDown 后观察到纵向滚动。
