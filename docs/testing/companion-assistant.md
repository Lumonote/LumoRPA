# 桌宠任务助手

主窗口顶栏“任务助手”直接打开文字面板，不开启麦克风。悬浮胶囊右侧的
键盘按钮也可展开面板。文字任务不依赖麦克风开关、
唤醒模型或收音权限；语音输入沿用主应用已有的设备、STT 与隐私配置。
两种输入都通过现有 Agent 服务规划和执行，敏感能力仍需在任务详情审批。

面板展示当前助手任务的规划、审批、执行进度、结果摘要与失败类别。
结果最多展示最近三条步骤摘要，总长度不超过 400 字符，并隐藏敏感字段及
常见文本凭证。完整输出通过“查看详情”打开当前关联的运行记录。
终态之后可以继续发送下一任务；发送失败会保留文字草稿。
摘要和结果在独立区域滚动，操作按钮、输入框与发送按钮保持可见。
结果区域支持键盘聚焦和滚动。Esc 收起后焦点回到展开按钮，Enter 可再次
展开并聚焦输入框；输入法组词中的 Esc 保留给输入法处理。

“停止任务”只取消助手关联的 runId。“×”停止收音及当前助手任务并收起；
它不会取消主窗口或后台任务。规划期间的停止会中断只读准备和规划请求；
若与持久化启动竞争，同一个取消 token 会阻止执行器派发后续步骤。
麦克风静音保留文字指令入口。

## 状态与窗口契约

- `capsule_status` 返回完整快照，`lumo://capsule-state` 发布同结构快照。
  每次更新带单调 `revision`；前端拒绝迟到响应。窗口重新加载或重新获得
  焦点时读取当前宿主快照。此恢复覆盖同一宿主进程内的窗口生命周期，
  不表示应用重启后自动续接桌宠任务。
- `capsule_submit_text {text}` 预留单个助手任务；忙时拒绝重复请求。
  启动时绑定实际 runId，并重放持久化事件，避免极快执行丢失结果。
  其他运行、重复 seq 与终态之后的迟到事件不改变当前助手任务。
- `capsule_control {action, runId}` 支持 `cancel` 和 `open`，拒绝过期 runId。
  打开详情时主窗口处理 `lumo://capsule-open-run {runId}`，精确选择该运行；
  不在最近 50 条列表中的运行也可加载。选中的运行使用独立投影，复用主窗口
  的事件订阅并补齐缺失序列；其他任务成为最新运行后，其审批和进度仍会更新。
- `capsule_resize {expanded}` 切换 310×76 与 390×390 的逻辑窗口尺寸。
  展开保持底边位置，并将窗口约束在原屏幕内。

输入框使用稳定 DOM，音量变化每个动画帧最多更新一次；窗口隐藏时暂停动画。
卸载释放事件订阅、窗口监听和动画帧，支持减少动态效果的系统偏好。

## 验证

```sh
cd apps/desktop/frontend
npm test
npm run lint
```

前端回归覆盖快照竞态、输入草稿/焦点、重复发送、终态重试、runId 控制、
窗口恢复、音量合并及卸载。Mission Control 回归覆盖指定运行选择、
连续打开不同运行、重复选择与迟到响应。

```sh
CARGO_INCREMENTAL=0 cargo test -p lumorpa-desktop --lib --locked
```

后端回归覆盖运行隔离、过期 runId、取消竞争、永不返回的规划取消、审批后
状态、持久化事件重放、结果摘要及凭证隐藏、终态后的语音状态和屏幕边界。
