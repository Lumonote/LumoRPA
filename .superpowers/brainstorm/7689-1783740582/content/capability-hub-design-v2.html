Capability Hub 修订：通用 MCP 导入器

管理中心其余设计保持不变；新增统一导入向导，将外部配置标准化为 LumoRPA 的 MCP Server Profile。

添加 MCP Server · 选择导入方式

自动发现

扫描用户已安装客户端的常见配置位置，识别 Claude Desktop、Cursor、Codex 等 `mcpServers` 配置。

配置文件

导入 JSON、JSONC、YAML 或 TOML；支持单个 Server 和完整 `mcpServers` 集合。

粘贴配置

直接粘贴通用 MCP JSON、启动命令、环境变量片段或远程服务 URL。

手动添加

通过 stdio、Streamable HTTP 或兼容旧服务的 SSE 参数表单逐项配置。

统一导入流水线

1

解析与识别

自动识别字段命名、传输协议、command/args/env、headers、URL 和多个 Server 条目。

2

预览与去重

展示即将新增、覆盖或跳过的服务；同名和同端点冲突由用户选择处理方式。

3

Secret 安全迁移

API Key、Token、密码和敏感 Header 不直接落盘，转换为 Vault 引用并允许重新输入。

4

连接与工具校验

导入后逐个测试连接、拉取工具 Schema、标注风险等级；失败项保留为未启用草稿。

兼容性原则

  • 内部使用稳定、版本化的 MCP Profile Schema
  • 外部格式通过 Import Adapter 转换，不污染执行层
  • 未知字段保留在扩展区，避免往返导入时丢失
  • 生成脱敏导入报告，便于排查失败条目

首版支持

  • 通用 `mcpServers` JSON/JSONC
  • stdio、Streamable HTTP、兼容 SSE
  • 文件、粘贴、客户端自动发现、手动表单
  • 批量导入、批量测试、按条目启用
