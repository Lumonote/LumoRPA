关键交互规则
低风险快速路径查询、只读工具和明确别名直接执行；胶囊显示“调用来源 + 目标”。
高风险确认路径写文件、发消息、桌面控制等展开确认卡；显示影响范围和关键参数。
不确定性处理候选能力置信度接近时只追问一个问题，不让 Agent 猜测执行。
语音打断“暂停 / 继续 / 取消 / 跳过这步 / 展开详情”在执行期间始终可用。
失败恢复节点变红并展示错误；Loop 可重试、换工具或重规划，高风险替代仍需确认。
改进闭环结束后可生成优化建议；只有用户审阅差异并批准，才写入版本化配置。
