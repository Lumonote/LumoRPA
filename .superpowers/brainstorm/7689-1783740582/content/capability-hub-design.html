管理规则

Skill

  • 本地文件/目录或 Git 地址导入
  • 解析、校验、版本、启停和依赖检查
  • 展示编译后的 Flow 与权限需求
  • 更新前显示差异，失败可回滚

MCP

  • 支持 stdio 与 Streamable HTTP
  • 凭据只存 Vault 引用，不进入配置和日志
  • 连接测试、工具发现、Schema 浏览和手动调用
  • 每个 Server/Tool 可单独启停和设置风险等级

Agent

  • 配置模型、预算、最大循环次数和并发数
  • 限定可见能力与默认权限策略
  • 查看 Memory、Trace 和评估结果
  • 改进提案必须差异审阅、批准、版本化、可回滚
